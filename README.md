# Lulu-the-Trex
Inspired by Google’s original T-Rex game, Lulu the T-Rex is a 2D dino running game created using the SFML Library in C++. However, Lulu the T-rex is not an endless running game! A sweet ending scene awaits you.

Don't forget to also install SFML-2.6.1!
